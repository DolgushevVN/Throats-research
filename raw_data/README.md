# raw_data

This folder stores the raw 3D images (`.raw`, `raw_dimension`³ voxels).

- Input: `<filename>_pores.raw` — pore segmentation (int32, one label per pore, `-1` = solid), prepared by the user.
- Input: `<filename>_<d>_p.raw`, `..._ux.raw`, `..._uy.raw`, `..._uz.raw` — pressure and velocity fields (`float32`) for the flow along `<d>` = `x`, `y`, `z`, computed by the user.
- Generated by the notebooks (int32): `<filename>_pore_boundaries.raw`, `<filename>_halfthroats.raw`, `<filename>_halfthroats_boundaries.raw`.
